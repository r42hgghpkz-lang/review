## 提交

1. 在本页作答。答案先只在这台浏览器里。
2. 用部署时发给你的同一地址打开，链接末尾带 `#k=` 和本机生成的密钥。页面读到后会立刻从地址栏去掉这段，不会把它写入草稿。不必再填底部口令。
3. 点「提交到私密收据」。页面用该密钥向网关换一段当次会话，再提交。会话放在本标签的内存里，**不使用跨站 Cookie**（手机 Safari 默认会丢掉这种 Cookie）。
4. 只有收到「已写入私密收据」并且带回执编号，才算送到。超时、断网、回执对不上：草稿还在，再点一次会沿用同一次提交，避免存成两份。
5. 成功之后草稿仍留在本机，不会被悄悄清掉。

`#k=` 不是 HTTP 请求的一部分，静态站看不到它。但它会留在浏览器历史里，复制或转发整段链接也会把密钥带出去。用完不要把带 `#k=` 的地址分享出去。

`gateway.json` 里的 `gateway` 目前是空的。空着的时候按钮会说明网关还没配置，不会把答案发到任何地方。上线前由部署的人把这里改成公网 HTTPS 网关的源（只有地址，没有口令、没有令牌）。

导出 JSON / 复制到剪贴板只是本机备份，不是提交。

本目录没有读回入口。莉莉丝在私密包所在的机器上读收据，不经过这个静态页。
